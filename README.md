# Remote Control Application for Vestel Smart TV

Vestel Smart TV cihazlarını yerel ağ (Wi-Fi / LAN) üzerinden kontrol etmek için geliştirilmiş uzaktan kumanda uygulaması.

- **📱 iOS & Android Mobil Uygulama (`mobile/`):** React Native & Expo ile geliştirilmiş, iPhone üzerinde bilgisayardan bağımsız çalışan mobil uzaktan kumanda uygulaması. Kurulum adımları için 👉 **[mobile/README.md](mobile/README.md)**
- **🖥️ Masaüstü Uygulaması (Kök dizin):** Python & PyQt5 ile geliştirilmiş masaüstü sürümü (`python main.py`).
